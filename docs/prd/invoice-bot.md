# Telegram-бот счетов — mdtask

## MVP

Бот запущен на VPS в `/opt/bitrix-invoice-bot` через Docker Compose. Он принимает PDF/XLSX, локально распознаёт реквизиты, показывает редактируемую сводку и после подтверждения отправляет один прямой запрос в Битрикс. Telegram-трафик идёт через системный Xray SOCKS5 на `127.0.0.1:10808`; Битрикс использует отдельный клиент без proxy.

Команды эксплуатации, конфигурация, архитектура и ограничения описаны в `README.md`.
