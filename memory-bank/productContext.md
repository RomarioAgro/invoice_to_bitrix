# Product Context

## Пользователи

Сотрудники, которые получают счета и создают связанные элементы в Битрикс через Telegram.

## Основные сценарии

Разрешённый пользователь в личном Telegram-чате отправляет PDF/XLSX с необязательной подписью-описанием, проходит автоматическое заполнение пропусков, проверку/исправление реквизитов, выбор типа и статьи ДДС, обязательный ввод номера задачи, подтверждение либо отмену. После успешной отправки бот показывает ссылку на созданную сделку, если Битрикс её вернул.

## Ограничения

Доступ только по непустому белому списку Telegram User ID и только из private chat. Один активный счёт, файл до 5 МБ, PDF до 2 страниц, три ручные HTTP-попытки. Реальный production smoke test требует подтверждения файла и задачи.
