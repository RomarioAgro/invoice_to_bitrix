# Active Context

## Текущая задача

Добавлен ручной ввод срока оплаты в формате `ДД,ММ,ГГГГ`.

## Текущее состояние

При ручном заполнении поля `pay_before` бот принимает `ДД.ММ.ГГГГ` и `ДД,ММ,ГГГГ`; запятые нормализуются в точки до общей проверки и отправки. Формат даты счёта не изменён. Проходит 23 теста.

## Следующие действия

Пользовательская проверка ручного ввода срока оплаты через запятую.
