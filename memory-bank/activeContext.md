# Active Context

## Текущая задача

INV-001 реализована; ожидается пользовательский smoke test без автоматической production-отправки счёта.

## Текущее состояние

На VPS установлен и включён Xray, SOCKS5 слушает только loopback. Контейнер `bitrix-invoice-bot` healthy, restart count 0 после безопасного пересоздания.

## Следующие действия

Пользователю выполнить `/start`, загрузить тестовый файл и проверить сводку. Перед нажатием «Отправить» подтвердить конкретный файл и номер задачи.
