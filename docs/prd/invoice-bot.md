# Telegram-бот счетов — mdtask

## MVP

Бот запущен на VPS в `/opt/bitrix-invoice-bot` через Docker Compose. Он принимает PDF/XLSX, локально распознаёт реквизиты, показывает безопасную HTML-сводку и автоматически запрашивает незаполненные обязательные поля, включая номер задачи Битрикс. Для корректных ИНН рядом отображается найденное через DaData название организации. После подтверждения бот отправляет один прямой запрос в Битрикс. Telegram-трафик идёт через системный Xray SOCKS5 на `127.0.0.1:10808`; Битрикс и DaData используют отдельные прямые клиенты без proxy.

Команды эксплуатации, конфигурация, архитектура и ограничения описаны в `README.md`.
