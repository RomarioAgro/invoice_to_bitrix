# Active Context

## Текущая задача

Реализуется ТЗ 2.3: описание счёта берётся из подписи Telegram к файлу, а при пустой подписи запрашивается отдельно.

## Текущее состояние

ТЗ 2.3 развёрнуто на VPS; целевой Docker-образ проходит 15 тестов. Production-контейнер имеет статус `healthy`, число перезапусков — 0.

## Следующие действия

Пользователю отправить файл с подписью и убедиться, что подпись показана как описание, а отдельный вопрос об описании пропущен.
