# Active Context

## Текущая задача

INV-003 реализована и развёрнута по ТЗ 2.2. Ожидается пользовательский smoke test без автоматической production-отправки счёта.

## Текущее состояние

Контейнер healthy и содержит автоматический опрос, HTML-сводку, необязательную задачу и прямое DaData-обогащение ИНН. Xray по-прежнему используется только для Telegram.

## Следующие действия

Пользователю выполнить `/start`, загрузить тестовый файл, проверить автоматические вопросы и названия организаций. Перед реальным нажатием «Отправить» подтвердить конкретный файл; номер задачи теперь можно оставить пустым.
