# Active Context

## Текущая задача

Исправлено распознавание ИНН в банковской подписи `ИНН/КПП` на реальном PDF-счёте.

## Текущее состояние

Парсер поддерживает подписи `ИНН`, `ИНН:`, `ИНН №` и `ИНН/КПП`; изменение развёрнуто на VPS. Контейнер `healthy`, перезапусков 0, на VPS проходят 20 тестов.

## Следующие действия

Пользователю повторно загрузить проблемный счёт и проверить распознанные ИНН без production-отправки в Битрикс.
