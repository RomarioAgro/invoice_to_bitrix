# Project Brief

## Назначение

Автоматизировать перенос реквизитов счетов PDF/XLSX из Telegram в Битрикс с локальным распознаванием и проверкой пользователем.

## Границы

Входит один активный счёт на пользователя, локальный OCR/парсинг, ручное исправление, отправка файла и полей, очистка и Docker-развёртывание. Не входят очередь, автоповторы, восстановление состояния и проверка дубликатов.

## Критерии результата

Контейнер healthy на VPS, Telegram работает только через Xray, Битрикс — напрямую, тесты проходят, секреты отсутствуют в репозитории и runtime-логах.
