# Инструкция по занесению счёта через Telegram-бота

Бот: `@sbis_permission_bot`

## 1. Начало работы

Откройте личный чат с ботом и отправьте:

```text
/start
```

Бот работает только:

- с пользователями из белого списка;
- в личном чате — группы и каналы не поддерживаются.

Если появляется сообщение «У вас нет доступа к этому боту», обратитесь к администратору и передайте свой Telegram User ID.

## 2. Отправка счёта

Отправьте счёт одним файлом:

- PDF до 5 МБ и не более двух страниц;
- XLSX до 5 МБ.

Желательно добавить к файлу подпись — она станет описанием счёта, например:

```text
Ноутбук для нового сотрудника отдела продаж
```

Подпись нужно добавить именно при отправке файла. Если её нет, бот отдельно запросит описание.

## 3. Заполнение данных

Бот распознает счёт и покажет сводку. Незаполненные обязательные поля отмечаются символом `❗` и выделяются жирным.

Бот последовательно запросит недостающие данные:

1. номер счёта;
2. дату счёта;
3. ИНН заказчика;
4. ИНН поставщика;
5. сумму;
6. срок оплаты;
7. описание;
8. тип счёта;
9. статью ДДС;
10. номер задачи Битрикс.

Дату счёта вводите в формате:

```text
29.07.2026
```

Срок оплаты можно ввести с точками или запятыми:

```text
05.08.2026
05,08,2026
```

ИНН должен содержать 10 или 12 цифр. Бот распознаёт подписи `ИНН`, `ИНН:`, `ИНН №` и `ИНН/КПП`; если поле не найдено, его можно ввести вручную. Номер задачи Битрикс — обязательное положительное целое число.

## 4. Проверка и исправление

Проверьте итоговую сводку.

Доступные действия:

- «Продолжить» — перейти к подтверждению;
- «Изменить» — выбрать и исправить поле;
- «Отменить» — удалить текущий счёт.

Одновременно можно обрабатывать только один счёт. Чтобы загрузить другой, сначала завершите текущий или выполните:

```text
/cancel
```

## 5. Отправка в Битрикс

После проверки нажмите «Продолжить», затем подтвердите отправку.

При успешной обработке бот сообщит:

```text
Счёт успешно отправлен в Битрикс
```

Если Битрикс вернул ссылку на созданную сделку, бот добавит её к сообщению.

Не нажимайте кнопку отправки повторно, пока бот обрабатывает запрос.

## Полезные команды

- `/start` — начать работу;
- `/status` — показать состояние текущего счёта;
- `/cancel` — отменить обработку и удалить текущий счёт;
- `/help` — краткая справка.

Если файл не принимается, проверьте его формат, размер и количество страниц PDF.
