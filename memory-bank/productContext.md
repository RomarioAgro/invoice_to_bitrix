# Product Context

## Пользователи

Сотрудники, которые получают счета и создают связанные элементы в Битрикс через Telegram.

## Основные сценарии

Отправка PDF/XLSX, автоматическое заполнение пропусков по вопросам бота, проверка/исправление реквизитов, выбор типа и статьи ДДС, необязательный ввод задачи, подтверждение либо отмена.

## Ограничения

Один активный счёт, файл до 5 МБ, PDF до 2 страниц, три ручные HTTP-попытки. Реальный production smoke test требует подтверждения файла и задачи.
