# Active Context

## Текущая задача

INV-002 реализована: добавлена нормализация дат с русским названием месяца. Ожидается пользовательский smoke test без автоматической production-отправки счёта.

## Текущее состояние

На VPS установлен и включён Xray, SOCKS5 слушает только loopback. Контейнер обновлён версией с поддержкой дат вида `27 июля 2026`.

## Следующие действия

Пользователю выполнить `/start`, загрузить тестовый файл и проверить сводку. Перед нажатием «Отправить» подтвердить конкретный файл и номер задачи.
