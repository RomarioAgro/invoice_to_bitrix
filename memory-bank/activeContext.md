# Active Context

## Текущая задача

Реализуется ТЗ 2.4: закрытый доступ по белому списку Telegram User ID и запрет обработки вне личных чатов.

## Текущее состояние

ТЗ 2.4 развёрнуто на VPS; белый список содержит одного подтверждённого пользователя. Целевой Docker-образ проходит 19 тестов, production-контейнер `healthy`, перезапусков 0.

## Следующие действия

Пользователю проверить `/start` разрешённым аккаунтом. Для полного негативного smoke test при необходимости использовать отдельный неразрешённый аккаунт и тестовую группу.
